Highlights

The whole pitch, six cards.

Menu, bar, themes, plugins

Omarchy's Quickshell shell, rebuilt as Hexciri end to end: the menu, the bar, the theme engine, plugins and keybinds, all included and renamed throughout. Hyprland only.

One update command

hexciri update covers system packages, AUR and the shell itself, unattended after a single confirm.

Themes that color everything

hexciri theme set recolors terminals, editors, browsers, Discord and Dorion, GTK/Qt, Spotify, the bar, lock screen and login in one hook. THPM themes Discord, Dorion, Zed and Heroic.

Minimal by default

Almost nothing installed; the shell, the theme engine and your apps are the system.

Nyxiri, if you want it

The bar, menu and workspaces suite is optional, never base install. Wallcraft too. They work with Hexciri when you ask for them.

Search, calc, clipboard

Super+Shift+S searches the web, Super+Shift+C calculates, Super+Ctrl+V recalls everything you copied. Menu modes, not apps.
