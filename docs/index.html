What you get

Four things, done properly.

A menu that does things

9 root entries, ~60 leaves — packages, sharing, hardware, themes, network, security, maintenance, gaming. Every row dispatches to a controller in bin/. Root is Mod+Alt+Space; Esc always goes back.

Themes that color everything

hexciri-theme set recolors terminals, editors, browsers, Discord, GTK/Qt, Spotify, the bar and lock in one hook. 22 Omarchy defaults ship; extras are one line each in a list.

Apps in, cruft out — once

Install adds kitty, Zed, OpenCode, Brave Origin, Nautilus and friends, and removes what they replace. Afterwards sync never touches packages: your choices stick.

Wallpapers you keep

Drop images in a folder; they merge into every theme's picker as read-only links and survive every theme swap. Extra folders (even NFS) are one line each.

The menu

Mod+Alt+Space opens nine buckets — packages, sharing, hardware, themes, system, updates and more. Every row runs a real script and Esc always goes back. Full menu map in the README.

Themes: one pick, 30+ apps

hexciri-theme set recolors terminals, editors, browsers, the bar and lock from one palette — 22 defaults ship and any GitHub theme is one command away. How themes work, in the README.

Wallpapers that survive theme changes

Drop images in a folder and they join every theme's picker as read-only links — theme swaps never touch them. How wallpapers work, in the README.

Apps: added & removed

One-time swap at install — kitty, Zed, Brave Origin, Nautilus in, replaced stock apps out — then hands off forever. Full list with reasons in the README.

The keys that matter

Mod = Super. Mod+Alt+Space menu, Mod+Space launcher, Mod+K searches every keybind. More keys in the README.
