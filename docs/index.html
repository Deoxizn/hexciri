Arch × Niri × Noctalia

curl -LO https://hexciri.dirty.pizza/hexciri && sh hexciri

Install

  1. Flash the Arch ISO, boot UEFI, connect network (iwctl for wifi).
  2. Run the line above.
  3. Reboot → straight into Niri. Press Mod+K for the keybinding list.

The kernel is chosen automatically — stock linux, or linux-lts pinned on legacy NVIDIA; custom kernels are a post-install choice via hexciri-kernel. The disk is left unencrypted — login is the SDDM password greeter.

Channels & GPU

stable is month-held pkgs; bleeding is normal Arch rolling release. GPU setup runs at install: Turing+ gets nvidia-open 6xx, NVIDIA GTX 1xxx or older gets 580xx pinned to LTS, everything else gets mesa/vulkan.

Theme engine

One colors.toml recolors the whole desktop — Noctalia + Niri borders, kitty, fish, GTK, Qt, Discord, Spotify, Zed, Firefox, Steam and more — through a drop-in hook set. 22 Omarchy themes ship by default; extras are one owner/name per line in an editable list. Update ▸ Themes clones, pulls and prunes to match.

Your wallpapers survive theme changes — a persistent user store merges into the active theme's backgrounds as symlinks, so the picker shows theme images and your set, and a theme swap keeps your current wallpaper. Strata follows the theme live, no reopen needed.

Lists, with examples

Both systems are plain text — edit a list, run Update ▸ Themes / Update ▸ Wallpaper, done.

Extra themes — ~/.config/hexciri/theme-sources/extra.list, one owner/name per line:

# one theme per line, <owner>/<name> form
HANCORE-linux/aamis
OldJobobo/dracula

# full URL works for repos that don't follow the naming
https://github.com/someone/not-an-omarchy-theme

Extra wallpaper directories — ~/.config/hexciri/wallpaper-sources/extra.list, one path per line:

# one directory per line; ~/ expands
~/Pictures/Wallpapers
/mnt/Photos/wallpapers

Removing a line removes that theme or directory's wallpapers on the next sync — nothing is ever copied or deleted, extras are just symlinks. Not a list person? Drop files straight into ~/.config/hexciri/wallpapers and they merge at Update ▸ Wallpaper, persisting across theme changes.

Highlights

  • Your wallpapers survive theme changes — personal images merge into the active theme's backgrounds as symlinks and stay put across swaps.
  • Theme engine — one colors.toml + a 29-hook set recolors 30+ apps; themes are list-driven and Strata follows live.
  • Transparent terminals — kitty at reduced background opacity with niri window-effect blur behind it (no focus ring/border, which niri paints as a solid rectangle over the translucency).
  • Gaming — hexciri-gaming: Steam, Heroic, Lutris, RetroArch, Minecraft, Battle.net (umu + GE-Proton), GeForce NOW, Xbox Cloud, GPU setup, Xbox controllers.
  • Never-clobber config deploy — install.sh sha-tracks configs: untouched ones update in place; edited ones stay with the repo default as <file>.hexciri alongside.
  • List-driven everything — themes and wallpapers are just lists: extra themes are one owner/name per line in extra.list (Update ▸ Themes clones, pulls and prunes to match), and wallpaper dirs are one path per line in wallpaper-sources/extra.list — remove a line and it's gone on the next refresh.
