Why Hexciri

Your wallpapers survive theme changes

Drop your own images into ~/.config/hexciri/wallpapers — they show up in the picker beside the theme's own, and stay put across every theme swap.

One-click theme engine

A single click (or hexciri-theme-set <name>) recolors the whole desktop. 22 themes ship included; extras are one line each in a list, no technical tinkering.

Transparent terminals

kitty at reduced background opacity with niri window-effect blur behind it — see your wallpaper through the terminal.

Gaming, ready

Steam, Heroic, Lutris, RetroArch, Minecraft, Battle.net, GeForce NOW, Xbox Cloud — GPU setup and controllers handled.

A minimal Arch experience

Your system starts clean: Arch, Niri, and a themed shell — nothing you didn't ask for; add the rest on demand.

Everything's just files

Theming and state live in plain, readable lists and configs in your home — easy to tweak, back up, and version. Updates never overwrite your edits; an edited config stays yours with the new default saved alongside.

Install

  1. Flash the Arch ISO, boot UEFI, connect network (iwctl for wifi).
  2. Run the line above.
  3. Reboot → straight into Niri. Press Mod+K for the keybinding list.

No prompts to answer — kernel, GPU, and channel are all decided for you. The disk is left unencrypted; login is the SDDM password screen.

Themes

Switch the whole look of your desktop whenever you like — colors, windows, terminals and apps all change together. Pick a theme from the Themes menu or run hexciri-theme-set <name>.

22 themes ship included, and you can add more any time — extra themes are one line each (owner/name) in a simple list. Add a line, run Update ▸ Themes, done; remove the line and it's gone.

Your wallpapers stick around. Drop your own images into ~/.config/hexciri/wallpapers — they show up in the wallpaper picker beside the theme's own and survive every theme change.

Lists, with examples

Both lists are plain text files — add a line, run Update ▸ Themes (for themes) or Update ▸ Wallpaper (for wallpapers), done.

Extra themes — ~/.config/hexciri/theme-sources/extra.list, one owner/name per line:

# one theme per line, owner/name form
HANCORE-linux/aamis
OldJobobo/dracula

Extra wallpaper folders — ~/.config/hexciri/wallpaper-sources/extra.list, one folder per line (~ means your home):

~/Pictures/Wallpapers
/mnt/Photos/wallpapers

Not a list person? The plain ~/.config/hexciri/wallpapers folder works too — drop files in and they're picked up, no list entry needed, and they stay across theme changes.
