Hexciri

CachyOS plus a WM/Shell of your choice (Niri today, MangoWM planned). hexciri is just dotfiles: a theme hook and a menu. Not a distro. Not an installer.

Dots

curl -LO https://hexciri.dirty.pizza/install.sh
sh install.sh

That clones Deoxizn/hexciri (or uses your checkout), symlinks bin/* into ~/.local/bin, and re-applies the layer via hexciri-sync. Updating is a pull plus a re-run. Version is the git SHA.

What it does

  • Menu — every option dispatches to a real controller in bin/. Nothing dangles.
  • Theme hook — hexciri-theme-set recolors the desktop in one shot.
  • Keybindings, one source of truth — rendered into the WM config so they never drift.

It never touches the installer, kernel, GPU stack, or package manager. Those stay CachyOS's.
