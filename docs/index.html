CachyOS × your WM × nothing you didn't ask for.

What it does

A real menu

Every option dispatches to a controller in bin/. Not a menu of links — a menu of working scripts. Nothing dangles.

One hook colors 30+ apps

Terminals, Discord, GTK, the works. hexciri-theme-set recolors your entire desktop in one go.

Keybinds, one list

The same keys, always. Press Mod+K for the full list, any time. Rendered into the WM config so they never drift.

Wallpapers you keep

Drop your own in. They survive theme changes, everything.

Dots

Install CachyOS with a WM/Shell, then bring the dots — curl or clone, same script.

  1. curl -LO https://hexciri.dirty.pizza/install.sh && sh install.sh
  2. or git clone https://github.com/Deoxizn/hexciri.git ~/.local/opt/hexciri && ~/.local/opt/hexciri/install.sh

That symlinks the controllers into ~/.local/bin and re-applies the layer via hexciri-sync. Updating is a pull plus a re-run. Version is the git SHA.

What it never touches

The installer, the kernel, the GPU stack, the package manager. Those stay CachyOS's.
