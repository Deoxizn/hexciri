Hexciri V2

EOS base + shell

  • EndeavourOS base — minimal Arch, almost nothing installed
  • Forked Omarchy shell — Hyprland + Quickshell, rebuilt as Hexciri
  • One update command — hexciri update covers system, AUR and shell
  • Theme engine + THPM — Discord, Dorion, Zed and Heroic included
  • Nyxiri, if you want it — bar, menu and workspaces, optional not base
curl -LO https://hexciri.dirty.pizza/v2/bootstrap.sh; bash bootstrap.sh
