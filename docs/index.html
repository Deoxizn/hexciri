Themes: one pick, 30+ apps

colors.toml is the single source of truth. hexciri-theme-set goes live, expands generated configs, then fires every drop-in in hooks/theme-set.d/.

  • Generated: kitty, fuzzel, starship configs, straight from the palette.
  • Hooked: terminals, editors, browsers, Discord, GTK/Qt, Spotify, bar, lock and 20+ more — full list in the README.
  • Palette source (Themes > Palette source) is yours: Theme or Wallpaper (Material You). Swaps never flip it back.

22 defaults + handpicked extras

Defaults ride a sparse clone of omacom/omarchy (quattro); extras are one line per theme in config/theme-sources/extra.list — the list is the source of truth (sync installs, pulls, and prunes to match). Plus two hexciri originals in themes/: sakurazuki and various-arch.

Wallpapers that survive theme changes

Your images merge into the active theme as read-only zz-user-* symlinks — theme swaps only replace theme-owned files, so yours persist.

  • Store: drop images/folders in ~/.config/hexciri/wallpapers (Themes > Backgrounds opens it).
  • Extra dirs: one directory per line in the wallpaper sources list (Themes > Wallpaper dirs list) — ~/Pictures, absolute paths, even NFS mounts. Never copied, never deleted, only linked.
  • Refresh: Update > Wallpaper re-merges; every framework sync re-merges the store automatically.
