Arch × Niri × Noctalia

curl -LO https://hexciri.dirty.pizza/hexciri && sh hexciri

Install

  1. Flash the Arch ISO, boot UEFI, connect network (iwctl for wifi).
  2. Run the line above.
  3. Reboot → straight into Niri. Press Mod+K for the keybinding list.

The disk is left unencrypted — login is the SDDM password prompt (minimal themed greeter), no disk-encryption step to answer.

Channels & GPU

stable is month-held pkgs; bleeding is normal Arch rolling release. GPU setup runs at install: Turing+ gets nvidia-open 6xx, NVIDIA GTX 1xxx or older gets 580xx pinned to LTS, everything else gets mesa/vulkan.

Theme engine

One colors.toml recolors kitty, fuzzel, Strata, fish, Zed, Noctalia, Niri borders, and Qt (qt6ct Fusion palette) via hexciri-theme-set. Drop-ins live in ~/.config/hexciri/hooks/theme-set.d/.

Highlights

  • Transparent terminals — kitty at reduced background opacity with niri window-effect blur behind it. No focus ring / border: niri draws those as a solid rectangle behind the window, which would cover the translucency.
  • Gaming — hexciri-gaming: Steam, Heroic, Lutris, RetroArch, Minecraft, Battle.net (umu + GE-Proton), GeForce NOW, Xbox Cloud, GPU setup, Xbox controllers.
  • Never-clobber config deploy — install.sh sha-tracks configs: untouched ones update in place; edited ones stay with the repo default landing as <file>.hexciri alongside.
